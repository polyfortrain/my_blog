# 要件定義書

## 目的
毎日の記録を投稿・管理できる、自分専用のブログアプリケーションを開発する。

## 機能要件
| 要件ID | 対応する要求 | 機能名 | 内容 |
| ------ | ------------ | ------ | ---- |
| FR-01 | UR-01 | 記事一覧 | 投稿済みの記事のタイトルと投稿日時を、新しい投稿順に表示する。 |
| FR-02 | UR-01 | 記事詳細 | 一覧から選択した記事のタイトル・本文・投稿日時を表示する。 |
| FR-03 | UR-02 | 記事投稿 | タイトルと本文を入力して、新しい記事を保存する。 |
| FR-04 | UR-03 | 記事更新 | 投稿済みの記事のタイトルと本文を変更して保存する。 |
| FR-05 | UR-04 | 記事削除 | 選択した記事を、確認後に削除する。 |
| FR-06 | UR-05 | 記事検索 | タイトルまたは本文に、入力したキーワードを含む記事を一覧表示する。 |

## 扱うデータ
| 項目 | 内容 |
| ---- | ---- |
| 記事ID | 記事を識別する番号。自動で付与し、重複させない。 |
| タイトル | 記事のタイトル。入力必須。 |
| 本文 | 記事の本文。入力必須。 |
| 投稿日時 | 新規投稿時に自動で記録し、更新時も変更しない。 |

## 入力・表示のルール
- タイトルまたは本文が空欄・空白のみの場合は、保存せずにエラーを表示する。
- 記事がない場合は「記事がありません」と表示する。
- 検索結果が0件の場合は「該当する記事がありません」と表示する。
- 検索キーワードが空欄の場合は、すべての記事を表示する。
- 記事の削除確認でキャンセルした場合は、削除しない。

## 非機能要件・対象範囲
- 自分のPCで利用できること。
- アプリケーションを終了しても、保存した記事が残ること。

## 完成の確認
- 投稿した記事が一覧と詳細に表示される。
- 更新した内容が反映される。
- 削除した記事が一覧と検索結果に表示されなくなる。
- キーワードに一致する記事を検索できる。
- 再起動後も、保存した記事を確認できる。
